# Modern Cosmetic Mastery

Personal study site for **Dr. Kevon Rennie** — ceramic inlays/onlays/overlays (Track 1, modules 1–3) and veneers including chairside injection molding and direct composite alternatives (Track 2, modules 4–7). Lab-fabricated focus, Ivoclar-first materials.

Live: **https://von-ops.github.io/cosmetic-mastery/**

Each module folder has `index.html` (lesson with original inline SVG diagrams, embedded videos, source-linked clinical photographs and vignettes), `study-sheet.html`, `quiz.html` (12 questions, two attempts, spaced review) and `protocol.html` (printable next-day chairside protocol).

Shared pages: `materials.html` (Ivoclar matrix + IFU parameter ledger I01–I09), `references.html` (15 PubMed-indexed references, IFUs, 6 videos, photo sources), `holds.html` (clinical holds and verification status).
