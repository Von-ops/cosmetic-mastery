How each module works

  1. Diagnose your level — answer the opening prompts before reading.
  2. Lesson — short sections with original diagrams, vetted videos and source-linked clinical photos; mark each section done (saved in this browser).
  3. Teach-back — explain it in plain language, then answer the application question.
  4. Quiz — 12 questions, two attempts each (hint, then reveal). Misses go into a spaced-review queue for day 1, 3, 7 and 21.
  5. Protocol — print the next-day chairside card: armamentarium, Ivoclar materials, numbered steps with IFU-verified values, checkpoints, pitfalls and open items.
